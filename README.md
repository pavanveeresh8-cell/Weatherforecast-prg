# Weather Forecast Project

## Description
This is a simple Weather Forecast web application that shows the current weather and a 5-day forecast for any city.

## Technologies Used
- HTML
- CSS
- JavaScript
- OpenWeather API

## Features
- Search weather by city
- Current temperature
- Humidity
- Wind speed
- 5-day weather forecast
- Dark mode
